## Long description

Turn an idea into a focused Product Plan, practical System Architecture, and supervised Agent Team. Define first-release scope, user journeys, components, data flows, tool permissions, handoffs, approval gates, and tests. Connect the reviewed work into an implementation plan or a scoped Codex handoff. Each relevant artifact can include a link to Codelit templates so you can explore the next step.

This skills-only plugin provides planning guidance, reference material, and reusable templates. It does not connect to your Codelit account, transfer generated drafts to Codelit, run independent agents, or deploy software. Live actions require a separately configured, authorized integration.

## Three starter prompts

1. Use Codelit to create a Product Plan for my idea with first-release scope, user stories, and acceptance criteria.
2. Use Codelit to explain this architecture simply, then review failure paths, data boundaries, and approvals.
3. Use Codelit to design a small agent team with tool permissions, handoffs, approval gates, and tests.
